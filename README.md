# 오닐 RS 스캐너

Python 3.10 이상에서 실행:

```bash
pip install -r requirements.txt
streamlit run app.py
```

터미널에 표시되는 http://localhost:8501 주소를 브라우저에서 여세요.

- 데이터: pykrx를 통한 KRX/네이버 일봉 및 투자자 수급. 외부 API 정책 변경이나 호출 제한에 따라 실패할 수 있습니다.
- RS: 3/6/9/12개월 수익률을 40/20/20/20 가중해 전체 코스피·코스닥 종목 중 백분위 등급으로 변환합니다. IBD 공식 RS와 다릅니다.
- 정렬: RS 등급 우선, 같은 등급에서 수급/거래량/상승채널 보조점수 순.
- 채널: 최근 60거래일 로그종가 선형회귀 ±2표준편차. 상승기울기이며 위치 0~65%면 양호.
- 제한: 장중 실시간 데이터가 아닙니다. 수급은 약 12달력일 합산이고, RS 기간은 달력일 근사입니다. 수급 누락 종목은 0으로 처리하므로 실제 0과 미수집을 구별하지 못합니다. 데이터 소스 변경 시 코드 수정이 필요할 수 있습니다.
- 최초 분석은 RS 통과 후보 각각의 일봉을 조회해 수분 이상 걸릴 수 있습니다. 조회 실패는 가상 데이터로 대체하지 않습니다.


## 갤럭시에서 사용하기
이 앱은 서버에 배포한 뒤 휴대폰 브라우저로 접속합니다.
1. `app.py`, `requirements.txt`를 GitHub 저장소에 업로드합니다.
2. https://share.streamlit.io/ 에서 저장소를 연결하고 `app.py`를 지정해 배포합니다.
3. 배포된 주소를 갤럭시 크롬으로 열고 메뉴에서 '홈 화면에 추가'를 선택합니다.
4. pykrx 데이터 소스는 호스팅 환경에서 접근이 제한될 수 있으며 첫 분석은 오래 걸릴 수 있습니다.

# 오닐 RS V5.19 통합 소스 패키지 — 실주문 차단 상태

이 패키지는 대화에서 만든 기존 모듈을 **한 번에** 업로드할 수 있도록 모은 것입니다. 별도 단계별 ZIP을 반복 업로드할 필요가 없습니다.

## 실제 상태
- V5.10 포착 후보 보고서 읽기: 지원 (보고서가 별도로 공급되어야 함)
- Supabase 주문 의도 저장/중복 방지 및 KIS 당일 주문 조회: 모듈 존재
- 후보 생성기와 매수 엔진 자동 연결: 미완성
- 완전한 계좌 위험 관리 및 과거/미확인 주문 복구: 미완성
- KIS 실주문 전송: 명시적으로 차단, 주문 0건

## 사용
기존 GitHub 저장소의 동일 이름 파일과 비교해 검토 후 일괄 적용하세요. 기존 스캐너, 시크릿, 워크플로를 삭제하지 마세요. 이 ZIP만으로 실전 자동매매가 시작되지 않습니다.

`v519_candidate_adapter.py`는 `v5_10_report.json` 형식의 최신 보고서를 받아 **매수 허가가 없는** 후보를 생성합니다. 예시 2026-10-27 보고서는 오래됐고 검증된 가격/수량이 없으므로 주문에 사용할 수 없습니다.

주의: Supabase의 비상정지 플래그를 임의로 해제하거나 GitHub Actions에서 LIVE_ENABLED/KIS_ALLOW_ORDER를 true로 변경하지 마세요. 포착 후보, KIS 시세, 계좌 잔고, 미체결 및 일별 손실, 주문 전후 복구가 같은 실행에서 확인되어야 합니다.
